等差数列：每次多同样多

看数列：2，5，8，11，14，…。相邻两个数相减，结果总是 3。这样的数列叫等差数列。

2+3 →5+3 →8+3 →11

记住两个名字

首项：第一个数，记作 a1。
公差：每次加的同一个数，记作 d。

往后走几步

第 n 项 = 首项 + 走了 (n−1) 步 × 公差。
不是 n 步，因为第一项还没有走。

第 n 项 = 首项 + (n − 1) × 公差

初中符号写法：an = a1 + (n − 1)d

先判断：相邻两项相减，差相同，就是等差数列。

生活里也常见：例如存钱计划中，每天都比昨天多存 3 元。

小提醒：等差数列的“差”可以是正数、负数，也可以是 0；只要每次加的是同一个数就行。

例题：求第 20 项

等差数列 5，8，11，… 的第 20 项是多少？

第 1 步：a1 = 5，d = 3，n = 20。
第 2 步：代入通项公式。
a20 = 5 + (20 − 1) × 3 = 62

等比数列：每次变成同样的倍数

看数列：1，2，4，8，16，…。相邻两个数相除，结果总是 2。这样的数列叫等比数列。

1×2 →2×2 →4×2 →8

也有两个名字

首项：第一个数，还是 a1。
公比：每次乘的同一个数，记作 q。

每走一步就乘一次

第 n 项 = 首项 × 公比的 (n−1) 次方。
第一项还没乘，所以指数是 0。

第 n 项 = 首项 × 公比的 (n − 1) 次方

读作：第 n 项等于首项乘“公比的 (n−1) 次方”。初中符号写法：an = a1 × qn−1

先判断：相邻两项相除，比相同，就是等比数列；除数不能是 0。

生活里也常见：细胞分裂时，1 个变 2 个，2 个变 4 个。

和等差数列不同：等比数列看的是“除法”。例如 8 ÷ 4 = 2，所以这里的公比是 2。

例题：求前 5 项的和

等比数列 3，6，12，… 的前 5 项和是多少？

第 1 步：a1 = 3，q = 2，n = 5。
第 2 步：代入求和公式。
S5 = 3(25 − 1)2 − 1 = 93

图形面积法：把分数和“看见”

有时等比数列的项越来越小，例如：1/2，1/4，1/8，1/16，…。它们加起来会是多少？我们把一个正方形当成 1，用不同颜色的面积来表示每一项。

每一步都在补空白

  • 第 1 块：1/2
  • 第 2 块：1/4
  • 第 3 块：1/8
  • 第 4 块：1/16
已显示 0 / 4 块
12 + 14 + 18 + 116 = 1516
有限四项1516还剩：1 − 1516 = 116 空白。
无限相加1继续加下去，空白无限缩小，和等于整个正方形。
很重要：前面四块只加到 15/16，还没有填满。只有当公比满足 −1 < q < 1 时，项才会越变越小，我们才能计算无限多项的总和；若 q > 1，项会越来越大，不存在有限的总和。

一眼分清楚

比较什么？等差数列等比数列
相邻两项相减，差相同相除，比相同
关键量公差 d公比 q
长串求和倒序相加，两头配对错位相加，中间消掉
容易弄错第 n 项是走了 n−1 步公比用“除”，不是用“减”
