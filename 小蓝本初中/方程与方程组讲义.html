0什么是方程

方程是含有未知数的等式。方程的核心思想是：通过建立等量关系，将实际问题或数学问题转化为关于未知数的等式，再运用代数方法求解。

基本概念

方程：含有未知数的等式，如 \(2x + 3 = 7\)。

方程的解：使等式成立的未知数的值。

解方程：求方程的解的过程。

方程的分类

分类标准类型
按未知数个数一元方程、二元方程、多元方程
按最高次数一次方程、二次方程、高次方程
按表达形式整式方程、分式方程、无理方程

本书按"一次方程→二次方程→方程组→特殊方程"的顺序，系统介绍各类方程的解法与技巧。

上 篇 · 一 次 方 程

1看 a 与 1

本章从最基础的问题出发：方程中系数 \(a\) 与常数 \(1\) 的关系如何影响方程的解。这看似简单，实则是理解含参方程的起点。

含参方程的分类讨论

核心问题

讨论方程 \(ax = b\) 的解：

\[ \begin{cases} a \neq 0 & \Rightarrow x = \dfrac{b}{a} \quad \text{（唯一解）} \\[6pt] a = 0,\; b \neq 0 & \Rightarrow \text{无解} \\[4pt] a = 0,\; b = 0 & \Rightarrow \text{无穷多解} \end{cases} \]

这一分类思想贯穿全书：含参数的方程，必须对参数的不同取值分别讨论解的情况。

含参方程的"三分法"（唯一解 / 无解 / 无穷多解）是代数方程理论的基本框架。即使在高次方程中，这一思想仍然适用。

2一元一次方程

基本解法

一元一次方程 \(ax + b = 0 (a \ne 0)\) 的标准解法流程：

  1. 去分母——等式两边同乘最小公倍数。
  2. 去括号——按分配律展开。
  3. 移项——含 \(x\) 的项移到一边，常数移到另一边。
  4. 合并同类项——化简为 \(ax = b\) 的形式。
  5. 系数化为 1——两边同除以 \(a\)。

含参一次方程

当方程的系数含有字母参数时，需要对参数进行分类讨论（见第1章的三分法）。竞赛中的典型问题是确定参数取何值时方程有唯一解、无解或无穷多解。

移项变号是最容易出错的地方。记住：移过等号的项必须变号。

3一次方程的简单应用

将实际问题转化为方程是数学建模的第一步。关键在于找准等量关系。

常见应用类型

类型核心等量关系
行程问题路程 = 速度 × 时间
工程问题工作量 = 效率 × 时间
浓度问题溶质 = 溶液 × 浓度
利润问题利润 = 售价 − 成本
年龄问题年龄差不变

列方程的思维步骤

  1. 设未知数——选一个量作为 \(x\)（通常选题目问的量，或选中间量使关系最简单）。
  2. 列等量关系——用 \(x\) 表示其他量，找出等式。
  3. 解方程——用标准方法求解。
  4. 检验——代入原题验证，排除不合理解。

4一次方程技巧

竞赛中的一次方程问题往往需要特殊技巧，而不仅仅是按部就班的运算。

常用技巧

整体代入

不急于展开，而是将某个子表达式视为整体。例如 \(3(x+1) - 2(x+1) = 5\)，直接合并为 \((x+1) = 5\)。

巧用比例

当方程中含有分数或比例关系时，利用比例的性质（如合比、分比定理）可以大幅简化运算。

绝对值方程

方法
\[ |ax + b| = c\text{（}c \ge 0\text{）} \text{等价于} ax + b = c \text{或} ax + b = -c\text{，分别求解即可。} \]
一次方程技巧·核心思维

①观察结构再动手——不要一上来就去括号；②寻找对称性——左右两边结构相似时可以整体处理；③善用特殊值检验——解出答案后代入原式快速验证。

5二元一次方程组

两种基本消元法

代入消元法
\[ \text{从一个方程解出一个变量（如} x = ...\text{），代入另一个方程，化为一元方程。} \]
加减消元法
\[ \text{将两个方程乘以适当系数后相加或相减，消去一个变量。} \]

解的判别

对于方程组 \(a_{1}x + b_{1}y = c_{1}, a_{2}x + b_{2}y = c_{2}\)：

\[ \begin{cases} \dfrac{a_1}{a_2} \neq \dfrac{b_1}{b_2} & \text{唯一解} \\[6pt] \dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} \neq \dfrac{c_1}{c_2} & \text{无解} \\[6pt] \dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \dfrac{c_1}{c_2} & \text{无穷多解} \end{cases} \]
从几何角度看，二元一次方程组的解对应两条直线的交点情况：相交（唯一解）、平行（无解）、重合（无穷多解）。

6多元一次方程组

三元及以上方程组

解多元一次方程组的核心策略是逐步消元：每次消去一个变量，将多元问题逐步降为一元问题。

  1. 选定要消去的变量（通常选系数最简单的）。
  2. 利用加减法或代入法消去该变量，得到减少一个变量的方程组。
  3. 重复消元，直到化为一元方程。
  4. 逐步回代，求出所有变量。

对称方程组

当方程组具有对称结构时，可以利用对称性简化。例如令 \(s = x + y, p = xy\)，将对称关系转化为关于 \(s, p\) 的方程。

多元消元·选变量的原则

①优先消去在多个方程中系数相同或成比例的变量；②优先消去系数为 1 或 −1 的变量（避免分数运算）；③若方程组有轮换/对称结构，先利用结构特征简化。

中 篇 · 二 次 方 程

7配方法

配方法是代数学中最基本也最强大的技巧之一，是连接一次方程与二次方程的桥梁。

基本原理

配方公式
\[ ax^{2} + bx + c = a\!\left(x + \frac{b}{2a}\right)^{\!2} + c - \frac{b^{2}}{4a} \]

配方法的三大应用

应用说明
解二次方程将一般二次方程化为 \((x+m)^{2} = n\) 的形式，直接开方
求最值配方后直接读出顶点坐标，确定最大/最小值
证明不等式将表达式化为完全平方之和，利用"平方 ≥ 0"得出结论
配方时记住口诀："二次项系数提出来，一次项系数除以二再平方，加上再减去。"这是推导求根公式的核心步骤。

8一元二次方程

四种解法

方法适用情形关键操作
直接开平方法形如 \((x+m)^{2} = n\)两边开方，注意 ±
配方法一般二次方程化为 \((x+m)^{2} = n\)
公式法任何二次方程代入求根公式
因式分解法左边可分解时用因式分解 + 零因子定理

求根公式与判别式

求根公式
\[ ax^{2} + bx + c = 0 \;\;(a \neq 0) \quad\Longrightarrow\quad x = \frac{-b \pm \sqrt{\Delta}}{2a}, \;\; \Delta = b^{2} - 4ac \]
判别式 \Delta 的作用
\[ \begin{cases} \Delta > 0 & \text{两个不等实根} \\ \Delta = 0 & \text{两个相等实根（重根）} \\ \Delta < 0 & \text{无实数根（共轭复根）} \end{cases} \]
使用因式分解法时，等号右边必须是 0。若 \((x-2)(x-3) = 0\)，则 \(x = 2\) 或 \(x = 3\)。但若 \((x-2)(x-3) = 1\)，不能直接令每个因式等于 1！

9可化为一元二次方程的方程

许多看似复杂的方程，通过适当的变换可以化为标准的一元二次方程来求解。

常见类型

双二次方程

\[ ax^{4} + bx^{2} + c = 0 \text{令} t = x^{2} (t \ge 0)\text{，化为} at^{2} + bt + c = 0\text{，解出} t \text{后再求} x\text{。} \]

倒数方程

形如 \(ax^{2} + bx + a = 0\)（首尾系数相同），两边除以 \(x\)，令 \(t = x + 1/x\) 化为二次方程。

换元法

当方程中出现重复的子表达式时，用新变量替换，降次处理。解出后务必回代并检验。

换元后求出的根必须回代检验——换元过程可能引入增根（不满足原方程的"假根"），或因变量替换的限制条件（如 \(t \ge 0\)）而舍去部分根。

10根与系数的关系

韦达定理（Vieta's Formulas）

定理
\[ x_1 + x_2 = -\frac{b}{a}\,, \qquad x_1 \cdot x_2 = \frac{c}{a} \]

韦达定理的应用

问题类型转化方法
求两根的对称式用 \(x_{1}+x_{2}\) 和 \(x_{1}x_{2}\) 表示，如 \(x_{1}^{2}+x_{2}^{2} = (x_{1}+x_{2})^{2}-2x_{1}x_{2}\)
构造新方程已知根的关系，构造以它们为根的新方程
判断根的符号由和与积的符号推断根的正负
含参方程的条件由韦达定理建立参数方程，结合判别式 \(\Delta \ge 0\)
使用韦达定理的前提是方程有两个实数根，即 \(\Delta \ge 0\)。忘记验证判别式是最常见的错误。
推广：高次方程的韦达定理

对于 \(n\) 次方程 \(aₙxⁿ + aₙ₋_{1}xⁿ⁻ + \cdots + a_{0} = 0\)，韦达定理推广为：

所有根之和 = \(-aₙ₋_{1}/aₙ\)；所有根两两乘积之和 = \(aₙ₋_{2}/aₙ\)；以此类推，正负号交替。

11高次方程

三次及以上的方程称为高次方程。在竞赛中，解高次方程的核心策略是降次。

降次方法

方法适用情形
因式分解能分解出一次因式或二次因式
换元法高次项与低次项存在对称关系
试根+综合除法整系数方程，先找有理根
配方法部分项可凑成完全平方/立方

特殊高次方程

倒数方程（回文方程）

系数关于中间对称的方程（如 \(2x^{4} + 3x^{3} - 5x^{2} + 3x + 2 = 0\)），可用 \(t = x + 1/x\) 降次。

二项方程

形如 \(xⁿ = a\) 的方程，利用单位根求解。

高次方程·求解策略
  1. 观察结构：是否有换元降次的可能？
  2. 尝试有理根：整系数时用有理根定理试根。
  3. 因式分解：提取已知因式后降次。
  4. 对剩余低次方程继续求解。

12分式方程

基本解法

分式方程是指未知数出现在分母中的方程。标准解法是去分母——等式两边同乘各分母的最小公倍式，化为整式方程。

  1. 确定各分母的最小公倍式。
  2. 等式两边同乘该公倍式，消去分母。
  3. 解化得的整式方程。
  4. 验根——将所得根代入原方程的分母，排除使分母为零的增根。
去分母过程必然可能引入增根（使某分母为零的根）。因此验根是不可省略的步骤。

竞赛技巧

分式方程的巧妙处理

拆项法：将复杂分式拆成部分分式之和，如 \(1/(x(x+1)) = 1/x - 1/(x+1)\)。

换元法：当分式中出现重复结构时，设子表达式为新变量。

对称处理：若方程关于某些分式对称，利用对称性简化。

13无理方程

无理方程是指含有未知数的根式（如 \(\sqrt(x+1)\)）的方程。

基本解法

核心策略是去根号：将含根号的项移到等号一侧，两边平方，化为有理方程。

  1. 整理方程，使根号项尽量集中在一侧。
  2. 两边平方，消去一个根号。
  3. 若仍有根号，重复平方。
  4. 解化得的有理方程。
  5. 验根——代入原方程检验，排除增根。
平方过程会引入增根（因为 \(a^{2} = b^{2}\) 不能推出 \(a = b\)，也可能 \(a = -b\)）。所有根都必须代入原方程验证。
有时可以通过换元（令根号内的表达式为新变量）来避免反复平方，使运算更简洁。

下 篇 · 方 程 组 与 专 题

14二次方程组

二次方程组是指至少含有一个二次方程的方程组。其解法核心是消元降次。

常见类型与解法

一个一次 + 一个二次

从一次方程解出一个变量，代入二次方程，化为一个一元二次方程。

两个二次方程

通过加减消去二次项（或某个特定的高次项），降为一次方程，再代入求解。

对称方程组

典型方法
\[ \text{当方程组关于} x, y \text{对称时，令} s = x + y, p = xy\text{，} \text{将方程组化为关于} s, p \text{的方程组，解出后再求} x, y\text{。} \text{此时} x, y \text{是方程} t^{2} - st + p = 0 \text{的两个根。} \]
对称方程组中，\((x, y)\) 和 \((y, x)\) 总是成对出现的解。利用韦达定理和 \(s, p\) 换元可以系统求出所有解。

15一次不定方程的整数解

不定方程是指未知数个数多于方程个数的方程，通常有无穷多组实数解，但整数解可能有限。

二元一次不定方程

标准形式
\[ ax + by = c\text{（}a, b, c \text{为整数）} \text{有整数解的充要条件：}gcd(a, b) | c\text{（即} a, b \text{的最大公约数整除} c\text{）。} \]

求解方法

  1. 用辗转相除法（扩展欧几里得算法）求出一组特解 \((x_{0}, y_{0})\)。
  2. 通解公式：\(x = x_{0} + (b/d)t, y = y_{0} - (a/d)t\)，其中 \(d = gcd(a,b)\)，\(t\) 为任意整数。
  3. 若有限制条件（如正整数解），由通解中的不等式确定 \(t\) 的范围。
竞赛中的常用技巧

整除分析法：将方程变形为 \(x = (c - by)/a\)，要求 \(a | (c - by)\)，由此确定 \(y\) 的条件。

模运算法：对某个数取模，利用同余关系缩小搜索范围。

16二次方程的整数根

确定一元二次方程何时有整数根，以及求出所有整数根，是竞赛中的高频考点。

整系数方程的整数根

必要条件
\[ \text{对于首一方程} x^{2} + bx + c = 0\text{（}b, c \text{为整数）：} \text{整数根} x_{1}, x_{2} \text{必整除常数项} c\text{。} \text{且} \Delta = b^{2} - 4c \text{必须是完全平方数。} \]

常用方法

方法思路
判别式法令 \(\Delta = k^{2}\)，将问题转化为关于 \(k\) 的不定方程
韦达定理法利用 \(x_{1}+x_{2} = -b\)，\(x_{1}x_{2} = c\)，枚举 \(c\) 的因数对
因式分解法将方程左边分解为 \((x-x_{1})(x-x_{2}) = 0\)
模运算法对特定数取模，排除不可能的情况
含参二次方程的整数根问题，通常需要同时满足两个条件：① \(\Delta\) 为完全平方数；② \((-b \pm \sqrt\Delta) / (2a)\) 为整数。这两个条件缺一不可。

17一元二次方程的应用

二次方程的应用题比一次方程更复杂，关键在于建立正确的等量关系并合理设元。

典型应用场景

场景建模要点
面积问题利用面积公式建立二次关系
增长率问题连续增长：终值 = 初值 × (1+r)ⁿ
抛物线运动位移 = 初速 × 时间 − ½g × 时间²
最优化问题利用配方求顶点，确定最大/最小值
几何中的二次关系勾股定理、相似比等常产生二次方程
应用题的解必须符合实际意义。例如：长度不能为负、人数必须是正整数、增长率需合理等。解完方程后务必检验每个根的实际合理性。
二次方程应用·建模步骤
  1. 读题，明确已知量和未知量。
  2. 设未知数（选使关系最简单的量）。
  3. 用未知数表示其他相关量。
  4. 根据等量关系列方程。
  5. 解方程，检验根的合理性。

核心思维链

一元二次方程·问题解决框架
  1. 识别——确认是二次方程（或可化为二次方程的形式）。
  2. 化简——去分母、去根号、换元，化为标准形式 \(ax^{2} + bx + c = 0\)。
  3. 判别——计算 \(\Delta = b^{2} - 4ac\)，判断根的情况。
  4. 求解——选择最便捷的方法（因式分解优先，否则用公式）。
  5. 验证——代入原方程检验，排除增根或不合理解。
  6. 利用——根据题意进一步利用根的信息（韦达定理、构造新方程等）。
一元二次方程公式速查

求根公式：\(x = (-b \pm \sqrt(b^{2}-4ac)) / (2a)\)

韦达定理：\(x_{1} + x_{2} = -b/a\)，\(x_{1}x_{2} = c/a\)

判别式：\(\Delta = b^{2} - 4ac\)

顶点坐标：\((-b/2a, -\Delta/4a)\)

对称轴：\(x = -b/2a\)

常用恒等式：

\(x_{1}^{2} + x_{2}^{2} = (x_{1}+x_{2})^{2} - 2x_{1}x_{2}\)

\(|x_{1} - x_{2}| = \sqrt\Delta / |a|\)

\(x_{1}^{3} + x_{2}^{3} = (x_{1}+x_{2})^{3} - 3x_{1}x_{2}(x_{1}+x_{2})\)
