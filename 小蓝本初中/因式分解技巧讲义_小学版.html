写在前面：什么是"因式分解"？

你一定会拆分数字吧？比如 12 = 3 × 4，把一个大数拆成几个小数相乘——这就是"分解因数"。

因式分解，就是把这个本领从数字升级到字母算式（多项式）。比如把 x² − 1 拆成 (x+1)(x−1)。

什么是因式分解

一切从这里开始

想象你有一盒 12 块巧克力，你可以把它看成 3 × 4 或 2 × 6。不管怎么拆，总数不变。

因式分解就是对"字母算式"做同样的事——把一个复杂的大算式，拆成几个简单的小算式相乘的形式。

为什么学因式分解？

因式分解可以让复杂的问题变简单。就像你算 99 × 37 时，如果发现 99 = 100 − 1，就可以用 3700 − 37 = 3663 快速算出来。因式分解就是帮你找到这种"巧妙拆法"。

两个重要规则

规则一：拆到底

每个小算式都不能再拆了才算完成。就像 12 = 2 × 6 还没拆完（6 还能拆成 2 × 3），要写成 12 = 2 × 2 × 3 才对。

规则二：乘回去验证

不确定拆得对不对？把几个小算式乘回去，看看是不是等于原来的大算式。这是最好的检验方法！

1

提公因式

第一个工具：找出"大家都有"的部分

你和 3 个好朋友每人都有 2 支铅笔。那一共有多少支？

2 + 2 + 2 + 2 = 2 × 4 = 8 支。"每人都有 2 支"——这个"2"就是公因式，把它提出来就行了！

怎么做？

  1. 找公因式——看看每一项里"大家都有的部分"是什么。
  2. 提出来——把公因式写到括号外面。
  3. 写剩下的——每一项除以公因式后剩下的，写到括号里面。

比如 \(6x + 9\)：

\(6x\) 里面有 \(3 \times 2x\)；\(9\) 里面有 \(3 \times 3\)。

"大家都有"的是 3，提出来：

6x + 9 = 3 × 2x + 3

要注意的事

一定要提干净！比如 \(4x^{2} + 8x\) 的公因式是 \(4x\)（不只是 4，也不只是 x），提完得到 \(4x(x + 2)\)。

别忘了留 1！比如 \(5x + 5\)，提出 5 后，第二项剩的是 1，不是"空"：\(5(x + 1)\)。

字母也能当公因式！如果算式里有 \(x(x+1) + 2(x+1)\)，你会发现"大家都有 \((x+1)\)"，所以：

\(x(x+1) + 2(x+1) = (x+1)(x+2)\)

把 \((x+1)\) 当成一个"整体"来提。

2

应用公式

记住几个"万能拆法"

有些算式长得特别像固定的"模型"，只要认出来，就能直接拆。

模型一：平方差

你有一个大正方形（边长 a），挖掉一个小正方形（边长 b），剩下的面积可以拼成一个长条——这就是"平方差"。

\[ a^{2} - b^{2} = (a + b)(a - b) \]

\(x^{2} - 9 = x^{2} - 3^{2} = (x + 3)(x - 3)\)

\(4x^{2} - 25 = (2x)^{2} - 5^{2} = (2x + 5)(2x - 5)\)

加法不行！\(a^{2} + b^{2}\) 在实数范围内拆不了。只有"减"才能用平方差。

模型二：完全平方

\[ a^{2} + 2ab + b^{2} = (a + b)^{2} a^{2} - 2ab + b^{2} = (a - b)^{2} \]

\(x^{2} + 6x + 9 = x^{2} + 2·x·3 + 3^{2} = (x + 3)^{2}\)

看，首尾两项分别是 \(x\) 和 \(3\) 的平方，中间恰好是 \(2 \times x \times 3\)！

模型三：立方和与立方差

\[ a^{3} + b^{3} = (a + b)(a^{2} - ab + b^{2}) a^{3} - b^{3} = (a - b)(a^{2} + ab + b^{2}) \]

看到"两个立方数相加或相减"，就用这个公式。注意中间项的符号和公式方向是反过来的。

模型四：完全立方

\[ a^{3} + 3a^{2}b + 3ab^{2} + b^{3} = (a + b)^{3} \]

看到系数是 1, 3, 3, 1，就是完全立方的信号！

Sophie Germain 魔法公式：

\(a⁴ + 4b⁴ = (a^{2} + 2b^{2} + 2ab)(a^{2} + 2b^{2} - 2ab)\)

用这个公式可以证明 \(21984 + 1\) 不是质数——它看起来像个质数，其实可以拆成两个数相乘！

分组分解

项数多的时候，先"分队"再各个击破

你有 8 个同学要搬桌子，桌子太重搬不动。怎么办？分成两组，每组 4 人搬一张小桌子——问题就解决了！

分组分解就是这个道理：4 项以上的算式，先分成小组，每组内部先分解，再看组与组之间能不能继续合并。

三步走

  1. 分组——把各项分成两组（或更多组）。
  2. 组内分解——每组内部提公因式或套公式。
  3. 组间合并——看看各组的结果有没有"新的公因式"，再提一次。

分解 \(ax + ay + bx + by\)：

分成两组：\((ax + ay)\) 和 \((bx + by)\)

组内提公因式：\(a(x+y)\) 和 \(b(x+y)\)

发现都有 \((x+y)\)，再提一次：

a(x+y) + b(x+y) = (a + b)(x + y)

"加零"的技巧

有时候算式怎么分都分不动。这时可以凭空加上一对相反数（加起来等于零，不改变原式的值），来创造分组的机会：

\(x⁴ + x^{2} + 1 = x⁴ + \textbf{2x^{2}} + 1 \textbf{- x^{2}} \;\;← 加了 +x^{2} 和 -x^{2} = (x^{2} + 1)^{2} - x^{2} \;\;← 完全平方！ = (x^{2} + x + 1)(x^{2} - x + 1) \;\;← 平方差！\)

4

拆项与添项

把一项拆成两项，或凭空添加"一对好朋友"

你在拼拼图，发现差一块拼不上。这时你把一块大拼图拆成两小块，或者从旁边借一块（同时也要还一块），让图案完整——这就是拆项添项。

拆开中间项

对于 \(x^{2} + 5x + 6\)，中间项 \(5x\) 可以拆成 \(2x + 3x\)：

\(x^{2} + 5x + 6\)

\(= x^{2} + 2x + 3x + 6\)    ← 把 5x 拆成 2x + 3x

\(= x(x+2) + 3(x+2)\)    ← 分组提公因式

\(= (x+3)(x+2)\)

拆的秘诀：找两个数，加起来等于 5（中间项系数），乘起来等于 6（常数项）。2 和 3 刚好满足！

无中生有（加零法）

\(x⁴ + 4\) 看着根本没法拆？

加上 \(+4x^{2}\) 和 \(-4x^{2}\)（加起来是零，不改变原式）：

\(x⁴ + 4x^{2} + 4 - 4x^{2} = (x^{2} + 2)^{2} - (2x)^{2} = (x^{2} + 2x + 2)(x^{2} - 2x + 2)\)

凭空变出了完全平方，再用平方差，搞定！

配方法

配方法是一种通用的拆项策略：把算式的一部分凑成完全平方，然后用平方差公式。

配方三步曲
  1. 选出一部分项，准备凑完全平方。
  2. 加上缺的项，同时减去同样的项（保持值不变）。
  3. 用 \(A^{2} - B^{2} = (A+B)(A-B)\) 完成分解。

十字相乘

拆二次三项式的"超级武器"

十字相乘是第四章"拆开中间项"的系统化版本。对于 \(x^{2} + bx + c\) 这类算式，有一个快速的方法。

最简单的情形

\[ x^{2} + bx + c = (x + m)(x + n) \]

其中 \(m + n = b\)，\(m \times n = c\)

翻译成大白话：找两个数，加起来是中间那个数，乘起来是最后那个数。

\(x^{2} + 7x + 12\)：找两个数加起来是 7、乘起来是 12 → 3 和 4

所以 \(x^{2} + 7x + 12 = (x + 3)(x + 4)\)

\(x^{2} - x - 12\)：找两个数加起来是 −1、乘起来是 −12 → 3 和 −4

所以 \(x^{2} - x - 12 = (x + 3)(x - 4)\)

首项系数不是 1 怎么办？

比如 \(6x^{2} + 7x + 2\)，需要把 6 和 2 都拆开，然后"交叉相乘"：

2x × 3x = 6x²
1 × 2 = 2

交叉相乘再相加：\(2x \times 2 + 3x \times 1 = 4x + 3x = 7x\) ✓ 正好等于中间项！

所以 \(6x^{2} + 7x + 2 = (2x + 1)(3x + 2)\)

快捷判断：如果一个算式各项系数加起来等于零（比如 \(3x^{2} - 5x + 2\)，3 − 5 + 2 = 0），那么 \((x - 1)\) 一定是它的因式！

二元二次式的分解

两个字母、最高二次——十字相乘的升级版

之前的方法都是一个字母 \(x\) 的事。如果有两个字母呢？比如 \(x^{2} + 3xy + 2y^{2} + 2x + y - 3\)？

分步来

  1. 先不管一次项和常数，只看最高次的部分 \(x^{2} + 3xy + 2y^{2}\)，用十字相乘拆成 \((x + y)(x + 2y)\)。
  2. 设分解形式为 \((x + y + a)(x + 2y + b)\)，展开后和原式比较系数，求出 \(a\) 和 \(b\)。
  3. 展开验证，确认分解正确。
能不能分解？

不是所有二元二次式都能分解。判断方法：把原式看成关于 \(x\) 的二次方程，算出判别式。如果判别式本身恰好是某个算式的完全平方，就能分解；否则就不行。

综合运用

把前面学到的工具组合起来

真实的问题不会只用一种方法。这一章教你四个"组合技"。

换元法——给复杂的东西起个名字

假设你每天都要带"语文课本+数学课本+英语课本"去学校，说起来太长，你就说"书包"。换元就是给一个复杂的式子取个短名字。

分解 \((x^{2}+x+1)(x^{2}+x+2) - 12\)

令 \(t = x^{2}+x\)，原式变成：

\((t+1)(t+2) - 12 = t^{2}+3t - 10 = (t+5)(t-2)\)

把 \(t\) 换回来：\((x^{2}+x+5)(x^{2}+x-2)\)

检查一下 \(x^{2}+x-2\) 还能不能拆？能！\(= (x+2)(x-1)\)

最终答案：\((x^{2}+x+5)(x+2)(x-1)\)

选主元——挑一个字母当"主角"

多字母的算式，选一个字母当主角（按它的次数从高到低排列），把其他字母当"背景"。选对了主角，问题就简单很多。

先展开再重新拆

有时候原式已经是乘法形式，但里面还能进一步拆。这时先展开，再重新组合。

\((x+1)(x+2)(x+3)(x+4) + 1\)

把第1个和第4个配对、第2个和第3个配对：

\((x^{2}+5x+4)(x^{2}+5x+6) + 1\)

令 \(t = x^{2}+5x+5\)，变成 \((t-1)(t+1)+1 = t^{2} = (x^{2}+5x+5)^{2}\)

因式定理试根

把 \(x = 1, -1, 2, -2, ...\) 一个一个代进去试。如果代入某个数后算式变成 0，那 \((x - 那个数)\) 就是一个因式！

多项式的一次因式

用"代入法"找因式，像侦探破案

想象你是一个侦探，要找出"谁是嫌疑人"。你的方法是：把每个人叫来问话（代入不同的数），看谁的反应是"零"（即让算式等于零），那他就是"凶手"（因式）！

余数定理

\[ \text{把} x = a \text{代入多项式} f(x)\text{，得到的值} f(a) \text{就是} f(x) \text{除以} (x - a) \text{的余数。} \]

特别地，如果 \(f(a) = 0\)，说明 \((x - a)\) 能整除 \(f(x)\)，也就是说 \((x - a)\) 是 \(f(x)\) 的因式。这就叫因式定理。

有理根定理——缩小嫌疑人范围

不用一个一个试！有理根定理告诉你嫌疑人只可能在有限的人选中：

\[ \text{如果} p/q \text{是多项式的根，} \text{那么} p \text{整除最后一项（常数项），}q \text{整除第一项（最高次项系数）。} \]

\(2x^{3} - 3x^{2} - 3x + 2\)

常数项 = 2，因数：±1, ±2

首项系数 = 2，因数：±1, ±2

候选根：±1, ±2, ±1/2

代入 x = −1：2(−1) − 3(1) − 3(−1) + 2 = −2 − 3 + 3 + 2 = 0 ✓

所以 \((x + 1)\) 是因式！用除法除掉后继续处理。

待定系数法

先猜长什么样，再算具体数字

你看到一个被布盖住的物品，猜它是一张桌子（有4条腿和一个平面）。你先把"桌子"的框架画出来，然后掀开布量一量，填入具体的长宽高数字。

待定系数法就是这个思路：先猜分解后的"形状"，再算出里面的未知数字。

怎么做？

分解 \(x⁴ + 2x^{3} - 7x^{2} - 8x + 12\)

猜形状：假设它能拆成两个二次式：

\((x^{2} + ax + b)(x^{2} + cx + d)\)

展开右边：

\(x⁴ + (a+c)x^{3} + (b+d+ac)x^{2} + (ad+bc)x + bd\)

逐项对比系数：

\(a+c = 2\)，\(b+d+ac = -7\)，\(ad+bc = -8\)，\(bd = 12\)

解这个方程组，就能找到 a, b, c, d 的具体值。

待定系数法的方程组通常很难解。在竞赛中，一般是其他方法都用不了的时候才用它。

轮换式与对称式

变量们"排排坐"的美妙规律

想象三个人 a、b、c 围坐在圆桌旁。如果不管怎么轮流换座位（a坐b的位置，b坐c的位置，c坐a的位置），你看到的画面都一样——这就是"轮换对称"。

两种类型

对称式 vs 轮换式

对称式：交换任意两个字母，式子不变。比如 \(a^{2} + b^{2} + ab\)，把 a 和 b 换一下还是它。

轮换式：按 a→b→c→a 轮换，式子不变。比如 \(a^{2}b + b^{2}c + c^{2}a\)。

对称式一定是轮换式，但轮换式不一定是对称式。

分解的秘诀

  1. 试一个因式：令某个字母 = 0（比如令 a = 0），看看式子是不是变成 0。如果是，说明含有 a 这个因式。
  2. 自动推广：因为式子是对称的，如果 a 是因式，那 b 和 c 也一定是因式。一下就找到了三个因式！
  3. 凑次数：算算已有的因式次数加起来是多少，和原式次数一比，就知道还差什么。
  4. 定系数：比较某一项的系数，算出最后那个常数。

经典案例

\[ a^{3} + b^{3} + c^{3} - 3abc = (a + b + c)(a^{2} + b^{2} + c^{2} - ab - bc - ca) \]

这是一个非常重要的公式。第二个括号还可以写成 \(\frac{1}{2}[(a-b)^{2} + (b-c)^{2} + (c-a)^{2}]\)，只有当 a = b = c 时才等于零。

实数集与复数集内的分解

不同的"世界"里，拆法不一样

同样一块蛋糕，在不同大小的聚会里切法不同：2个人切两半，4个人切四份，8个人切八份。因式分解也一样——在"有理数的世界""实数的世界""复数的世界"里，能拆到什么程度是不一样的。

三个"世界"

世界特点拆到什么程度
有理数世界只用分数和整数有些式子拆不了
实数世界可以用小数、根号最复杂拆到二次
复数世界可以用虚数 i全部能拆成一次式

代数基本定理

\[ n \text{次多项式在复数世界里} \text{一定能拆成} n \text{个一次因式相乘。} \]

这是一个非常深刻的定理——它保证了任何多项式最终都能被"彻底拆开"。

单位根

\(x⁷ - 1 = 0\) 的 n 个解叫做"n 次单位根"，它们均匀分布在复平面上的单位圆上。

\(x^{3} - 1 = (x - 1)(x^{2} + x + 1)\)

其中 \(x^{2} + x + 1\) 在有理数里拆不了，但在复数里可以继续拆。

共轭配对

如果一个实系数多项式有一个复数根 \(a + bi\)，那它的"镜像" \(a - bi\) 也一定是根。这两个根配对后变成一个实数二次式：

\((x - (a+bi))(x - (a-bi)) = x^{2} - 2ax + (a^{2}+b^{2})\)

既约多项式

哪些式子"拆不了"？怎么证明？

在数字里，2、3、5、7 这些质数"拆不了"（除了 1 和它本身没有其他因数）。多项式里也有"拆不了"的家伙，叫做既约多项式（或者"不可约多项式"）。怎么判断一个多项式是不是既约的呢？

艾森斯坦判别法

这是判断"拆不了"的最有名工具：

\[ \text{如果能找到一个质数} p\text{，使得：}  1. p \text{不整除最高次项系数}  2. p \text{整除其余所有项的系数}  3. p^{2} \text{不整除常数项} \text{那么这个多项式在有理数世界里拆不了！} \]

\(x^{3} + 6x^{2} + 12x + 8\)

试试 p = 2：最高次项系数是 1，2 不整除 1 ✓

其余系数 6, 12, 8 都被 2 整除 ✓

常数项 8 被 4 (=2²) 整除 ✗ ——不满足条件 3！

所以不能直接用艾氏判别法（其实这个式子 = (x+2)³，是可约的）。

模 2 法

把所有系数除以 2 看余数（只看奇偶），变成一个只有 0 和 1 的简单式子。如果在"0-1 世界"里拆不了，那原来在有理数世界也拆不了。

分圆多项式

\(x⁷ - 1\) 在有理数世界里的"标准拆法"用到分圆多项式：

几个常见的分圆多项式（都是既约的）

\(\Phi1(x) = x - 1   \Phi2(x) = x + 1   \Phi3(x) = x^{2} + x + 1 \Phi4(x) = x^{2} + 1   \Phi6(x) = x^{2} - x + 1\)

如果 p 是质数：\(\Phip(x) = xp-1 + xp-2 + \cdots + x + 1\)

综合与应用：六字口诀

记住这六个字，遇到因式分解就不怕
提 → 套 → 分 → 变 → 试 → 验
口诀含义对应工具
提看看有没有公因式可以提出来第1章 提公因式
套看看能不能套用公式（平方差等）第2章 应用公式
分试试分组分解第3章 分组分解
变拆项、添项、换元、配方，改变样子第4、5、7章
试代入特殊值试根第8章 因式定理
验乘回去验证，检查是否拆到底第0章 基本规则

动手试试

分解 \(x^4 + 4\)。

思路：这个式子看起来很简单，没有公因式，也不是公式的样子。但我们可以"添项"——加上 \(4x^2\) 再减去 \(4x^2\)：

\[ x^4 + 4 = x^4 + 4x^2 + 4 - 4x^2 = (x^2 + 2)^2 - (2x)^2 = (x^2 + 2x + 2)(x^2 - 2x + 2) \]

这就是"变"的精髓——添项之后，就变成平方差公式了！

写在最后

因式分解没有"万能公式"，但有系统的思考方法。遇到一道题，按"提→套→分→变→试→验"的顺序走一遍，大部分问题都能解决。如果一条路走不通，换一种方法再试——灵活性才是数学最有趣的地方！
