0什么是组合数学

组合数学是研究离散对象的计数、存在性、构造与优化的数学分支。它不像代数那样依赖公式推导，也不像几何那样依赖图形论证，而是以逻辑推理和巧妙构造为核心。

组合数学的四大问题类型
类型核心问题本书对应章节
计数问题满足条件的对象有多少？第1章
存在性问题满足条件的对象是否一定存在？第2章（抽屉原理）
构造问题如何给对象赋予某种结构？第3章（染色）、第4章（操作）
最优化问题在约束下，最大值或最小值是多少？第5章

组合数学的魅力在于：问题往往看似简单，解法却需要深刻的洞察力。本书精选五类经典问题，展示组合思维的精妙之处。

1计数问题

计数是组合数学最基本的问题：在给定条件下，计算满足某种要求的对象个数。计数的核心思想是有序、不重、不漏。

两大基本原理

加法原理与乘法原理

加法原理：完成一件事有 \(n\) 类方法，第 \(i\) 类有 \(m_i\) 种方式，则总方法数为：

\[m_1 + m_2 + \cdots + m_n\]

乘法原理：完成一件事需 \(n\) 个步骤，第 \(i\) 步有 \(m_i\) 种方式，则总方法数为：

\[m_1 \times m_2 \times \cdots \times m_n\]

加法原理用于"分类"——各类互斥；乘法原理用于"分步"——各步独立。实际计数中，往往需要先分类再分步，两者交替使用。

阶乘

阶乘的定义

正整数 \(n\) 的阶乘（记作 \(n!\)）是从 \(1\) 到 \(n\) 所有正整数的乘积：

\[ n! = n \times (n-1) \times (n-2) \times \cdots \times 2 \times 1 \]

特别规定 \(0! = 1\)（空积约定）。

例如：\(3! = 3 \times 2 \times 1 = 6\)，\(5! = 5 \times 4 \times 3 \times 2 \times 1 = 120\)。

阶乘增长极其迅速：\(10! = 3{,}628{,}800\)，\(20! \approx 2.43 \times 10^{18}\)。它在计数中扮演核心角色——\(n!\) 恰好是 \(n\) 个不同元素全排列的数目。

排列与组合

排列数的推导

从 \(n\) 个不同元素中选出 \(m\) 个排成一列，有多少种排法？

第 1 个位置有 \(n\) 种选择，第 2 个位置有 \(n-1\) 种，……，第 \(m\) 个位置有 \(n-m+1\) 种。由乘法原理：

\[ \mathrm{A}_n^m = n(n-1)(n-2)\cdots(n-m+1) = \frac{n!}{(n-m)!} \]
组合数的推导

从 \(n\) 个不同元素中选出 \(m\) 个组成一组（不计顺序），有多少种选法？

可以先选 \(m\) 个再排列（\(\mathrm{A}_n^m\) 种），但同一组的 \(m\) 个元素有 \(m!\) 种排列都算同一种组合，故需除以 \(m!\)：

\[ \mathrm{C}_n^m = \binom{n}{m} = \frac{\mathrm{A}_n^m}{m!} = \frac{n!}{m!(n-m)!} \]
排列关注"顺序"，组合不关注"顺序"。选择问题用组合，排队问题用排列。两者关系：\(\mathrm{A}_n^m = \mathrm{C}_n^m \times m!\)。
组合恒等式（常用）
\[ \binom{n}{m} = \binom{n}{n-m} \quad \text{（对称性）} \] \[ \binom{n}{m} = \binom{n-1}{m-1} + \binom{n-1}{m} \quad \text{（Pascal 递推）} \] \[ \sum_{k=0}^{n} \binom{n}{k} = 2^n \quad \text{（二项式求和）} \]

容斥原理

当直接计数困难时，可以先"多算"再"扣除"——这就是容斥原理的思想。

容斥原理
\[ |A_1 \cup A_2 \cup \cdots \cup A_n| = \sum_{i}|A_i| - \sum_{i \lt j}|A_i \cap A_j| + \sum_{i \lt j \lt k}|A_i \cap A_j \cap A_k| - \cdots \]

简记为：加单个，减两个的交，加三个的交，……交替进行。

计数问题·常用策略
策略适用场景

示例：错排问题

\(n\) 封信装入 \(n\) 个信封，全部装错的方案数 \(D_n\)（错排数）：

\[ D_n = n!\sum_{k=0}^{n} \frac{(-1)^k}{k!} \]

前几项：\(D_1 = 0,\; D_2 = 1,\; D_3 = 2,\; D_4 = 9,\; D_5 = 44\)。

递推关系：\(D_n = (n-1)(D_{n-1} + D_{n-2})\)。

2抽屉原理

抽屉原理（又称鸽巢原理）是组合数学中最简单却最深刻的存在性定理之一。它的表述极其朴素，却常常能给出令人惊讶的结论。

基本原理

抽屉原理（基本形式）

将 \(n+1\) 个物品放入 \(n\) 个抽屉，则至少有一个抽屉里放进了 \(\geq 2\) 个物品。

抽屉原理（加强形式）

将 \(N\) 个物品放入 \(n\) 个抽屉，则至少有一个抽屉里放进了不少于

\[ \left\lceil \frac{N}{n} \right\rceil \]

个物品。其中 \(\lceil x \rceil\) 表示不小于 \(x\) 的最小整数。

抽屉原理的使用关键在于构造抽屉：如何把问题中的对象分成若干类（抽屉），使得同一类中的对象必然满足某种性质。

经典应用

例：整数和的整除性

任取 \(n\) 个整数 \(a_1, a_2, \ldots, a_n\)，其中必存在若干个连续项之和被 \(n\) 整除。

证明：考虑前缀和 \(S_k = a_1 + a_2 + \cdots + a_k\)（\(k = 1, 2, \ldots, n\)）。将每个 \(S_k\) 除以 \(n\) 取余数，余数取值范围为 \(0, 1, \ldots, n{-}1\)，共 \(n\) 种。

若某个 \(S_k \equiv 0 \pmod{n}\)，则 \(a_1 + \cdots + a_k\) 被 \(n\) 整除，证毕。

否则，\(n\) 个前缀和的余数只有 \(n{-}1\) 种非零取值，由抽屉原理，必存在 \(i < j\) 使得 \(S_i \equiv S_j \pmod{n}\)，于是 \(S_j - S_i = a_{i+1} + \cdots + a_j \equiv 0 \pmod{n}\)。

抽屉原理的精髓不在于定理本身，而在于"抽屉"的构造。同一个问题，抽屉构造得越巧妙，结论就越强。

抽屉原理的推广

名称内容
基本形式\(n+1\) 个物品 \(\to\) \(n\) 个抽屉，至少一个抽屉 \(\geq 2\)
加强形式\(N\) 个物品 \(\to\) \(n\) 个抽屉，至少一个抽屉 \(\geq \lceil N/n \rceil\)
无限形式（Ramsey 定理雏形）将无穷多个对象分类，则某类中必含无穷多个对象
更多经典应用

生日问题：23人中至少有两人同一天生日的概率超过50%。这是概率论中的抽屉原理思想。

Dirichlet 逼近定理：对任意无理数 \(\alpha\) 和正整数 \(N\)，存在整数 \(p, q\) 满足 \(1 \leq q \leq N\) 且

\[ \left|\alpha - \frac{p}{q}\right| < \frac{1}{qN} \]

证明思路：考虑 \(N+1\) 个数 \(\{k\alpha\}\)（\(k = 0, 1, \ldots, N\)）落入 \(N\) 个区间 \([i/N, (i+1)/N)\) 中。

3染色问题

染色问题研究如何给一组对象赋予"颜色"标签，使得相邻或相关的对象满足特定的颜色约束。染色问题在图论、组合几何和数论中都有重要应用。

基本染色计数

直线排列染色

用 \(k\) 种颜色给一排 \(n\) 个格子染色，相邻格子颜色不同，方案数为：

\[ k \cdot (k-1)^{n-1} \]

第一格有 \(k\) 种选择，之后每格只需避开前一格的颜色，有 \(k-1\) 种选择。

环形染色

用 \(k\) 种颜色给环形排列的 \(n\) 个格子染色，相邻格子颜色不同，方案数为：

\[ (k-1)^n + (-1)^n (k-1) \]

此公式可通过递推或容斥原理推导。

地图染色与色数

给地图（或图）的顶点/区域染色，使得相邻的顶点/区域颜色不同，所需的最少颜色数称为色数，记为 \(\chi\)。

结构色数 \(\chi\)
完全图 \(K_n\)\(n\)
偶环 \(C_{2k}\)\(2\)
奇环 \(C_{2k+1}\)\(3\)
树\(2\)
平面图（地图）\(\leq 4\)（四色定理）
四色定理断言：任何平面地图都可以用至多 4 种颜色染色，使得相邻区域颜色不同。这是第一个由计算机辅助证明的重大数学定理（1976年）。

染色问题的常用方法

染色问题·方法工具箱
方法适用场景核心思想
递推法直线/环形排列染色由 \(n{-}1\) 个的染色方案推 \(n\) 个
容斥法有限制条件的染色计数总方案数减去违反限制的方案数
构造法证明色数上界给出一种具体的染色方案

环形染色公式的递推推导

设环形 \(n\) 格用 \(k\) 色的合法染色数为 \(f(n)\)。将环"剪开"成直线，直线染色数为 \(k(k-1)^{n-1}\)。但直线染色中，首尾颜色相同的情况需要扣除。

首尾颜色相同的方案数恰好等于 \(f(n-1)\)（将首尾合并为一个格子，等价于 \(n{-}1\) 格的环）。于是：

\[ f(n) = k(k-1)^{n-1} - f(n-1) \]

以 \(f(3) = k(k-1)(k-2)\) 为初始值，解此递推即得 \(f(n) = (k-1)^n + (-1)^n(k-1)\)。

4操作与游戏

操作与游戏类问题研究在一系列规则操作下，系统状态如何变化，以及是否存在某种"必胜策略"。这类问题的核心思想是不变量——在操作过程中始终不变的量。

不变量方法

不变量原理

若一个量在每次操作后保持不变（或单调变化），则可以用它来证明某些状态不可达。

常见不变量类型：

类型特征
守恒量操作前后完全不变（如奇偶性、模余数）
单调量操作后严格增大或减小（用于证明终止性）
半不变量操作后在某些方面不变（如模 2 不变但绝对值可变）

经典不变量示例

奇偶不变量

在一个 \(n \times n\) 棋盘上，每次操作改变两个相邻格子的颜色（黑变白、白变黑）。问：能否从全白变成全黑？

分析：设黑格数为 \(B\)。每次操作改变两个格子，\(B\) 的变化为 \(\pm 2\) 或 \(0\)，故 \(B\) 的奇偶性不变。初始 \(B = 0\)（偶数），全黑时 \(B = n^2\)。若 \(n\) 为奇数，\(n^2\) 为奇数，奇偶性改变，不可达。

博弈与策略

策略窃取（Strategy Stealing）

在两人对称博弈中，若后手有必胜策略，则先手可以"窃取"该策略（先走一步无用棋，然后模仿后手策略），从而先手也有必胜策略——矛盾。因此：

对称博弈中，先手不会输（要么先手必胜，要么平局）。

配对策略

将棋盘/局面配对成对子，每次对手在一对中行动时，我方在另一元素中行动。若能完成配对，则我方必胜。

操作与游戏问题的精髓：先找不变量判断"能不能"，再找策略回答"怎么做"。不变量是组合博弈论的基石。
操作与游戏·分析框架
  1. 理解规则——明确每次操作改变什么、不改变什么。
  2. 寻找不变量——奇偶性、模余数、面积、权值之和等。
  3. 判断可达性——用不变量排除不可达状态。
  4. 构造策略——对可达目标，给出具体的操作步骤。
  5. 证明最优性——说明不存在更好的策略（常用反证法）。

5组合最值

组合最值问题研究在给定约束条件下，某个量的最大值或最小值。这类问题既要求证明上界（不可能更多），又要求构造达到上界的例子（确实能做到）。

基本方法

组合最值的双向证明

证明组合最值 \(M\) 需要两步：

步骤内容方法
上界证明证明任何方案都不超过 \(M\)不等式放缩、计数论证、极端原理
构造证明给出一个恰好达到 \(M\) 的方案显式构造、递推构造、概率方法

常用工具

极端原理

在所有满足条件的对象中，取"最极端"的一个（最大、最小、最长、最短等），利用其极端性推导性质。

双重计数

对同一个量用两种方式计数，建立等式或不等式。例如：计算"满足某关系的对数"，先按行计、再按列计，得到

\[ \sum_{i} r_i = \sum_{j} c_j = \text{总对数} \]

由此可推出不等式关系。

Turán 定理（极值图论的基石）

不含完全子图 \(K_{r+1}\) 的 \(n\) 顶点简单图，边数最多为：

\[ \text{ex}(n, K_{r+1}) = \left(1 - \frac{1}{r}\right)\frac{n^2}{2} \]

（渐近形式，精确值为 Turán 图 \(T(n,r)\) 的边数。）

组合最值·方法总结

组合最值·策略一览
策略核心思想典型场景

示例：Erdős–Ko–Rado 定理

设 \(n \geq 2k\)，\(\mathcal{F}\) 是 \(\{1, 2, \ldots, n\}\) 的 \(k\)-元子集族，且 \(\mathcal{F}\) 中任意两个集合有交集（称为"交族"）。则：

\[ |\mathcal{F}| \leq \binom{n-1}{k-1} \]

等号成立当且仅当 \(\mathcal{F}\) 是"星形族"——所有集合都包含某个固定元素。

上界证明：对集合族用循环移位法（Katona 方法）或双重计数。

构造：取 \(\mathcal{F} = \{S \subseteq \{1,\ldots,n\} : |S| = k,\; 1 \in S\}\)，则 \(|\mathcal{F}| = \binom{n-1}{k-1}\)。

组合最值问题的美在于"上界"与"构造"的完美契合——当两者恰好吻合时，便得到了精确答案。这种"紧"（tight）的感觉，是组合数学最优雅的时刻。
