写在前面：什么是"方程"？

方程就像一个天平：等号左边和右边必须一样重。

比如 x + 3 = 7，就是说"某个神秘数字加上 3，跟 7 一样重"。你的任务就是找出那个神秘数字！

这本书有 18 章，从最简单的天平（一次方程）一直讲到复杂的天平组（方程组）。我们一步一步来！

上 篇 · 一 次 方 程

1

看 a 与 1

参数变了，答案也会变

想象你有个方程 ax = 5。这里的 a 就像一个"开关"：

如果 a = 1，那 x = 5，简单！

如果 a = 0 呢？0 × x = 5？不管 x 是什么，0 乘以任何数都是 0，永远不等于 5——所以无解！

三种情况

方程 ax = b 的三种命运

a 不是 0：有唯一答案 x = b/a。比如 2x = 6，x = 3。

a 是 0，b 不是 0：无解。比如 0x = 5，不可能。

a 是 0，b 也是 0：任何数都行！比如 0x = 0，x 可以是任何数。

这就是"含参方程"的核心思想：参数的值不同，方程的命运就不同。

2

一元一次方程

最基础的天平

方程就像天平：左边放一堆东西，右边放另一堆，两边必须一样重。

解方程就是要把"神秘数字 x"单独放在天平一边，让另一边只剩已知的数字。

解题五步法

  1. 去分母——如果有分数，先让所有项都乘上公分母，消掉分数。
  2. 去括号——把括号展开（用分配律）。
  3. 搬家（移项）——把含 x 的项搬到左边，数字搬到右边。
  4. 合并——把同类项加在一起。
  5. 除过去——两边除以 x 的系数，让 x 变成"1个 x"。

解 \(3x + 5 = 2x + 9\)

把 2x 搬到左边（变号）：\(3x - 2x + 5 = 9\)

把 5 搬到右边（变号）：\(x = 9 - 5 = 4\)

验证：\(3(4)+5 = 17\)，\(2(4)+9 = 17\) ✓

搬家一定要变号！从左搬到右（或从右搬到左），加号变减号，减号变加号。这是最常见的错误！

一次方程的简单应用

用方程解决生活问题

小明买了 3 本笔记本和 1 支笔，一共花了 22 元。每支笔 4 元，每本笔记本多少元？

这就是方程大显身手的时候！设每本笔记本 x 元：3x + 4 = 22，解出 x = 6 元。

列方程的秘诀

四步搞定应用题
  1. 设——选一个不知道的数，叫它 x。
  2. 列——找到题目里"相等"的关系，写成等式。
  3. 解——用前面学的五步法解方程。
  4. 验——把答案代回题目看看对不对，合不合理。
题目类型关键等量关系
路程问题路程 = 速度 × 时间
买东西总价 = 单价 × 数量
年龄问题两个人的年龄差永远不变
工程问题工作总量 = 效率 × 时间

一次方程技巧

聪明人的快捷方式

整体法——别急着拆

如果你看到 3(x+1) − 2(x+1) = 5，别急着展开括号！

你会发现两边都有 (x+1)，就像"3 个苹果减去 2 个苹果"：

(3−2)(x+1) = 5，所以 x+1 = 5，x = 4。

绝对值方程

\[ |x - 3| = 5 \text{意思是：}"x \text{和} 3 \text{的距离是} 5" \]

所以 x 可以是 3+5 = 8，也可以是 3−5 = −2。两个答案！

检验大法：解完方程后，把答案代回原来的方程算一遍，看看等号两边是不是一样。这只需要 10 秒钟，但能避免大部分错误！

二元一次方程组

两个天平，两个秘密数字

你有两个天平的线索：

线索一：x + y = 10（两个神秘数字加起来是 10）

线索二：x − y = 4（一个比另一个大 4）

只有两条线索合在一起，才能确定 x 和 y 各是多少。这就是"方程组"。

两种解法

代入法——从一条线索推另一条

从线索一得到 \(x = 10 - y\)，代入线索二：

\((10-y) - y = 4\)，解出 \(y = 3\)，再算 \(x = 7\)。

加减法——两个天平叠在一起

把两个方程加起来：\((x+y) + (x-y) = 10 + 4\)

\(2x = 14\)，所以 \(x = 7\)，再算 \(y = 3\)。

三种结局

结局什么意思比方
唯一解两条线相交于一点两条路在十字路口相遇
无解两条平行线永不相交两条路永远平行，走不到一起
无穷多解两条线完全重合两条路其实是同一条路

多元一次方程组

三个或更多秘密数字

如果二元方程组像"两个线索找两个嫌疑人"，那三元方程组就是"三个线索找三个嫌疑人"。方法一样——一步一步消去，先变成两个未知数，再变成一个。

消元大法

  1. 挑一个最容易消掉的变量（系数是 1 或 −1 的最好）。
  2. 用加减法把这个变量从两个方程里消掉，得到少一个变量的新方程组。
  3. 重复，直到只剩一个变量，解出来。
  4. 把答案回代，一个个求出其他变量。

对称方程组的捷径：如果方程组里 x 和 y 地位相同（交换后方程不变），可以令 s = x + y，p = xy，把问题变简单。

配方法

把算式变成"完美方块"

想象你有一块不完整的正方形地砖，缺了一个角。你"借"来一小块补齐，就变成了完整的正方形——然后就可以用正方形的面积公式了！

配方法就是给算式"补角"，把它变成 (x + m)² 的完美形式。

怎么配？

\(x^{2} + 6x + 5 = 0\)

第一步：看一次项系数 6，除以 2 得 3，再平方得 9。

第二步：加上 9 再减去 9（保持等式不变）：

\(x^{2} + 6x + 9 - 9 + 5 = 0\)

第三步：前三项变成完全平方：

\((x + 3)^{2} - 4 = 0\)

第四步：移项开方：\((x+3)^{2} = 4\)，\(x+3 = \pm2\)

所以 \(x = -1\) 或 \(x = -5\)

配方口诀

"一次项系数除以 2，再平方，加上又减去"——这三步记住了，配方法就掌握了！

一元二次方程

有 x² 的方程

一次方程只有一个答案。但二次方程（有 x² 的方程）通常有两个答案！

就像问"什么数平方等于 9？"——答案可以是 3，也可以是 −3。

万能求根公式

\[ \text{对于} ax^{2} + bx + c = 0 x = (-b \pm \sqrt(b^{2}-4ac)) ⁄ (2a) \]

判别式——提前知道答案长什么样

Δ = b² − 4ac

Δ > 0：两个不同的答案（两个实数根）

Δ = 0：两个一样的答案（一个重根）

Δ < 0：没有实数答案（在实数范围内无解）

四种解法对比

方法什么时候用
直接开方方程已经长成 (x+m)² = n 的样子
配方法什么二次方程都行，但计算多
公式法万能！代入公式就能算
因式分解左边恰好能拆成两个因式相乘

用因式分解法的前提是右边必须等于 0！比如 \((x-2)(x-3) = 0\)，才能说 x=2 或 x=3。如果右边不是 0，就不能这样拆。

9

可化为一元二次方程的方程

披着复杂外衣的二次方程

有些方程看起来吓人（比如有 x⁴），但其实是"穿了马甲"的二次方程。只要给它"脱掉马甲"（换元），就变成了你熟悉的二次方程。

换元法

\(x⁴ - 5x^{2} + 6 = 0\)

令 \(t = x^{2}\)，方程变成：

\(t^{2} - 5t + 6 = 0\) → \((t-2)(t-3) = 0\)

所以 \(t = 2\) 或 \(t = 3\)

换回来：\(x^{2} = 2\) 或 \(x^{2} = 3\)

\(x = \pm\sqrt2\) 或 \(x = \pm\sqrt3\)，一共四个答案！

换元后解出来的答案，一定要换回来检查。有时候换元过程会引入"假答案"（增根），需要排除。

10

根与系数的关系

韦达定理——不计算就知道答案的秘密

你不需要解方程，就能知道两个答案加起来是多少、乘起来是多少。这就像不用打开礼物盒，就能知道里面礼物的总重量！

韦达定理

\[ \text{方程} ax^{2} + bx + c = 0 \text{的两个根} x₁ \text{和} x₂\text{：} x₁ + x₂ = -b/a  \text{（两根之和）} x₁ \times x₂ = c/a  \text{（两根之积）} \]

方程 \(x^{2} - 7x + 10 = 0\)：

两根之和 = \(7\)，两根之积 = \(10\)。

不用解方程就知道！当然，你可以验证：\(x = 2\) 和 \(x = 5\)，2+5 = 7，2×5 = 10 ✓

韦达定理能干什么？

知道了两根之和与积，你可以算出很多"关于根的表达式"：

\(x₁^{2} + x₂^{2} = (x₁+x₂)^{2} - 2x₁x₂ |x₁ - x₂| = \sqrt\Delta / |a|\)

这些都不用真的解方程！

用韦达定理之前，先确认方程确实有两个实数根——也就是 \(\Delta \ge 0\)。如果 \(\Delta < 0\)，根不是实数，韦达定理虽然成立但没什么用。

11

高次方程

三次、四次、五次……怎么办？

高次方程就像一个更复杂的密码锁——可能有3个、4个甚至更多答案。但别怕，核心策略只有一个字：降——把高次变成低次。

降次三板斧

方法一：试根 + 除法

先试试 x = 1, −1, 2, −2, ...，找到一个根后，用除法把方程"降一级"。

方法二：换元

比如 \(x⁴ - 5x^{2} + 6 = 0\)，令 \(t = x^{2}\) 就变成二次方程了。

方法三：因式分解

如果能把高次多项式拆成几个低次因式相乘，就大事化小了。

12

分式方程

x 藏在分母里

分式方程就是 x 躲在分母里的方程，比如 1/x + 1/(x+1) = 1。解决思路很简单：把分母"消灭"掉！

怎么消灭分母？

  1. 找到所有分母的"最小公倍数"。
  2. 等式两边都乘上这个公倍数——分母就全没了。
  3. 解化简后的普通方程。
  4. 验根！把答案代回原方程，检查有没有让某个分母变成 0 的——那种就是"假答案"，要扔掉。

消灭分母的过程一定会引入"假答案"的可能，所以验根绝对不能省略！

13

无理方程

根号里面有 x

无理方程就是根号里藏着 x 的方程，比如 √(x+3) = 5。怎么去掉根号？——两边平方！

解题步骤

\(\sqrt(2x + 1) = x - 1\)

两边平方：\(2x + 1 = (x-1)^{2} = x^{2} - 2x + 1\)

整理：\(x^{2} - 4x = 0\)，\(x(x-4) = 0\)

所以 \(x = 0\) 或 \(x = 4\)

验根：x = 0 代入原式：√1 = −1？不对！扔掉。

x = 4 代入：√9 = 3 ✓ 保留。

最终答案：\(x = 4\)

平方会把负数变成正数，所以一定会引入"假答案"。每个答案都必须代回原方程检查！

二次方程组

方程组里出现了 x²

之前的方程组都是"直线和直线相交"，现在方程组里有了"曲线"，可能交于两个点甚至更多！

一个一次 + 一个二次

从一次方程解出一个变量，代入二次方程，就变成了一个一元二次方程。因为二次方程可以有两个根，所以方程组通常有两组解。

对称方程组的妙招

如果方程组关于 x 和 y 对称（交换后不变），就用韦达定理：

令 \(s = x + y\)，\(p = xy\)，解出 s 和 p。

然后 x 和 y 就是方程 \(t^{2} - st + p = 0\) 的两个根！

一次不定方程的整数解

只找整数答案

你有 100 元，要买 7 元一支的笔和 3 元一块的橡皮，刚好花完。能买几支笔几块橡皮？

这就是"不定方程求整数解"——方程 7x + 3y = 100，但 x 和 y 必须是正整数。

怎么找整数解？

核心方法

把方程变形：\(y = (100 - 7x) / 3\)

要求 y 是整数，就要 \(100 - 7x\) 能被 3 整除。

逐一检验 x = 1, 2, 3, ...，找出所有让 y 也是正整数的组合。

\[ ax + by = c \text{有整数解的条件：} a \text{和} b \text{的最大公约数必须能整除} c \]
16

二次方程的整数根

什么时候答案刚好是整数？

二次方程的答案大多数是小数或无理数。但竞赛经常问："参数取什么值时，答案刚好是整数？"——就像要求飞镖必须正中靶心。

两个必要条件

整数根必须同时满足

条件一：判别式 \(\Delta = b^{2} - 4ac\) 必须是完全平方数（这样根号才能开得出来）。

条件二：\((-b \pm \sqrt\Delta) / (2a)\) 必须是整数（开方后的结果除以 2a 得整数）。

韦达定理法：如果方程是 \(x^{2} + bx + c = 0\)（首项系数为 1），那整数根必须整除 c。只要列出 c 的所有因数，逐个试就行了！

一元二次方程的应用

二次方程在生活中的用武之地

经典应用

类型例子
面积问题一块长方形草坪，长比宽多 3 米，面积 40 m²，求长和宽
连续增长存款 1000 元，年利率 r，两年后变成 1210 元，求 r
最值问题用 20 米栅栏围长方形，怎么围面积最大？
抛物线运动向上抛球，什么时候球达到最高点？

二次方程通常有两个根，但在应用题里，有些答案不合常理（比如长度是负数、人数是小数），必须排除！

求最大/最小值的秘诀

把二次表达式配方成 \(a(x - h)^{2} + k\) 的形式：

如果 a > 0（开口朝上），最小值是 k，在 x = h 时取到。

如果 a < 0（开口朝下），最大值是 k，在 x = h 时取到。

写在最后

方程的本质就是一个"等量关系"——一个天平。不管方程多复杂，核心思路永远不变：想办法把未知数单独放到天平的一边。一次方程用搬家，二次方程用配方或公式，高次方程用降次，分式方程用去分母——方法不同，但思想相通。掌握了这个思想，再复杂的方程也不怕！
