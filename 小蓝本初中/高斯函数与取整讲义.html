1什么是"取整"？

生活中我们经常需要把一个"带小数"的数归拢到最近的整数。比如电梯在第 3.7 层——不存在这个楼层，你要么在第 3 层，要么在第 4 层。取整就是给实数找一个最合适的整数"代表"。

但"找整数"有两种方向：向下（往更小的整数靠）和向上（往更大的整数靠）。对应的两个函数，分别叫"地板函数"和"天花板函数"。

2向下取整函数 \(\lfloor x \rfloor\)
定义

\(\lfloor x \rfloor\) 表示不超过 \(x\) 的最大整数，也叫"地板函数"（floor）。

通俗说法：在数轴上，从 \(x\) 出发往左走，碰到的第一个整数。

数轴图解：\(\lfloor x \rfloor\) 的含义

计算示例

正数

\(\lfloor 3.7 \rfloor = 3\)，\(\lfloor 5.99 \rfloor = 5\)，\(\lfloor 2.0 \rfloor = 2\)

负数（易错！）

\(\lfloor -1.2 \rfloor = -2\)，\(\lfloor -3.0 \rfloor = -3\)，\(\lfloor -0.5 \rfloor = -1\)

易错提醒：\(\lfloor -1.2 \rfloor = -2\)，不是 \(-1\)！因为"不超过 \(-1.2\) 的最大整数"是 \(-2\)（\(-2 \lt -1.2 \lt -1\)，而 \(-1\) 比 \(-1.2\) 大）。记住：向下取整永远往数轴左边靠。
3向上取整函数 \(\lceil x \rceil\)
定义

\(\lceil x \rceil\) 表示不小于 \(x\) 的最小整数，也叫"天花板函数"（ceiling）。

通俗说法：在数轴上，从 \(x\) 出发往右走，碰到的第一个整数。

数轴图解：\(\lceil x \rceil\) 的含义

计算示例

正数

\(\lceil 3.2 \rceil = 4\)，\(\lceil 5.01 \rceil = 6\)，\(\lceil 7.0 \rceil = 7\)

负数

\(\lceil -1.8 \rceil = -1\)，\(\lceil -4.0 \rceil = -4\)，\(\lceil -0.1 \rceil = 0\)

核心区别

当 \(x\) 本身就是整数时，\(\lfloor x \rfloor = \lceil x \rceil = x\)，两者相等。

当 \(x\) 不是整数时，\(\lfloor x \rfloor\) 取左边的整数，\(\lceil x \rceil\) 取右边的整数，且 \(\lceil x \rceil - \lfloor x \rfloor = 1\)。

5重要性质与公式
编号性质说明
①\(x - 1 \lt \lfloor x \rfloor \leq x \leq \lceil x \rceil \lt x + 1\)取整函数的基本不等式
②\(\lceil x \rceil - \lfloor x \rfloor = 0\) 或 \(1\)整数时差为 0，非整数时差为 1
③\(\lfloor x + n \rfloor = \lfloor x \rfloor + n\)（\(n \in \mathbb{Z}\)）整数可以"提出"取整符号
④\(\lceil x \rceil = -\lfloor -x \rfloor\)向上与向下取整的对偶关系
⑤\(\lfloor x \rfloor + \lfloor y \rfloor \leq \lfloor x + y \rfloor\)取整函数具有"次可加性"
⑥\(\left\lfloor \dfrac{n}{m} \right\rfloor\) = \(n \div m\) 的商\(n, m\) 为正整数时，取整就是整除
性质④的直观理解

对偶关系 \(\lceil x \rceil = -\lfloor -x \rfloor\)：把数轴"翻转"（取相反数），原来的"向上取整"就变成了"向下取整"。

验证：\(\lceil 2.3 \rceil = 3\)，而 \(-\lfloor -2.3 \rfloor = -(-3) = 3\)。✓

小数部分（分数部分）

任何实数 \(x\) 都可以唯一分解为：

\[ x = \lfloor x \rfloor + \{x\} \]

其中 \(\{x\} = x - \lfloor x \rfloor\) 称为 \(x\) 的小数部分，满足 \(0 \leq \{x\} \lt 1\)。

正数例子：\(3.7 = 3 + 0.7\)，故 \(\{3.7\} = 0.7\)。

负数例子：\(-1.2 = -2 + 0.8\)，故 \(\{-1.2\} = 0.8\)。（注意不是 \(-0.2\)！）

6阶梯函数图像

取整函数的图像呈"阶梯"状——在两个整数之间保持水平，在每个整数处"跳"一步。

\(y = \lfloor x \rfloor\)（向下取整）
\(y = \lceil x \rceil\)（向上取整）
读图要点：\(\lfloor x \rfloor\) 的每段左实右空（左闭右开），因为"不超过 \(x\)"包含左端整数。\(\lceil x \rceil\) 的每段左空右实（左开右闭），因为"不小于 \(x\)"包含右端整数。两幅图关于原点中心对称——这正是对偶关系 \(\lceil x \rceil = -\lfloor -x \rfloor\) 的几何体现。
7生活中的取整
🛗

电梯楼层

你在 3.7 层？不存在。
只能在第 3 层（向下）
或第 4 层（向上）。

📦

装箱问题

17 个球，每箱装 5 个。
需要 \(\lceil 17/5 \rceil = 4\) 箱。
3 箱不够，得用第 4 箱！

💰

整除与余数

\(\lfloor n/m \rfloor\) 就是商。
\(n - m\lfloor n/m \rfloor\) 就是余数。
取整 = 整除运算！

🎫

买票找零

票价 7 元，你有 20 元。
最多买 \(\lfloor 20/7 \rfloor = 2\) 张。
找零 \(20 - 14 = 6\) 元。

8经典例题
例 1：计算求和

求 \(\lfloor \sqrt{2} \rfloor + \lfloor \sqrt{3} \rfloor + \lfloor \sqrt{5} \rfloor + \lfloor \sqrt{7} \rfloor + \lfloor \sqrt{11} \rfloor\) 的值。

解：逐一估算：

\(\sqrt{2} \approx 1.414 \Rightarrow 1\)；\(\sqrt{3} \approx 1.732 \Rightarrow 1\)；\(\sqrt{5} \approx 2.236 \Rightarrow 2\)；\(\sqrt{7} \approx 2.646 \Rightarrow 2\)；\(\sqrt{11} \approx 3.317 \Rightarrow 3\)。

原式 = \(1 + 1 + 2 + 2 + 3 = \boxed{9}\)。

例 2：Hermite 恒等式

证明：对任意实数 \(x\) 和正整数 \(n\)，

\[ \lfloor x \rfloor + \left\lfloor x + \frac{1}{n} \right\rfloor + \left\lfloor x + \frac{2}{n} \right\rfloor + \cdots + \left\lfloor x + \frac{n-1}{n} \right\rfloor = \lfloor nx \rfloor \]

思路：设 \(x = k + \frac{j}{n} + \varepsilon\)，其中 \(k\) 为整数，\(0 \leq j \leq n-1\)，\(0 \leq \varepsilon \lt \frac{1}{n}\)。代入左边逐项计算即可验证。

当 \(n = 2\) 时的特例：\(\lfloor x \rfloor + \lfloor x + \tfrac{1}{2} \rfloor = \lfloor 2x \rfloor\)。

例 3：计数问题

在 \(1, 2, 3, \ldots, 100\) 中，有多少个整数 \(k\) 使得 \(\lfloor \sqrt{k} \rfloor\) 为奇数？

解：\(\lfloor \sqrt{k} \rfloor = m\) 当且仅当 \(m^2 \leq k \lt (m+1)^2\)，即 \(k \in [m^2,\, (m+1)^2 - 1]\)，共 \((m+1)^2 - m^2 = 2m + 1\) 个。

取 \(m\) 为奇数，且 \(m^2 \leq 100\)，即 \(m \in \{1, 3, 5, 7, 9\}\)：

\(m = 1\)：\(k \in [1, 3]\)，3 个。

\(m = 3\)：\(k \in [9, 15]\)，7 个。

\(m = 5\)：\(k \in [25, 35]\)，11 个。

\(m = 7\)：\(k \in [49, 63]\)，15 个。

\(m = 9\)：\(k \in [81, 99]\)，19 个。（注意：\(\lfloor\sqrt{100}\rfloor = 10\) 是偶数，故 \(k = 100\) 不计入。）

总计：\(3 + 7 + 11 + 15 + 19 = \boxed{55}\) 个。
