§ 0记号与预备知识

本书围绕竞赛中常用的解题方法与策略展开，分为代数、几何、数论、组合四篇。在正文开始之前，先统一全书使用的记号。

第 一 部 分
代 数 篇

1.1 巧用平方差

核心公式
\[a^2 - b^2 = (a+b)(a-b)\]

平方差公式看似简单，却是竞赛中因式分解、化简、估算的利器。

应用场景：① 连乘化简——构造 \((a-b)(a+b)\) 连锁消去；② 分母有理化——\(\frac{1}{\sqrt{a}+\sqrt{b}} = \frac{\sqrt{a}-\sqrt{b}}{a-b}\)；③ 整除性分析——将差值分解为乘积后分析因数。

1.2 恰当换元

换元的本质是简化问题结构：用新变量替代复杂表达式，使隐藏的对称性或简洁结构显现。

换元策略
换元类型适用场景示例
对称换元含 \(x + \frac{1}{x}\) 型令 \(t = x + \frac{1}{x}\)
整体换元重复出现的子表达式令 \(u = x^2 + x\)
三角换元含 \(\sqrt{a^2 - x^2}\) 型令 \(x = a\sin\theta\)
均值换元含对称变量令 \(x = s+d,\; y = s-d\)

1.3 判别式的应用

判别式

对一元二次方程 \(ax^2 + bx + c = 0\)（\(a \neq 0\)），判别式

\[\Delta = b^2 - 4ac\]

\(\Delta \gt 0\)：两个不等实根；\(\Delta = 0\)：两个相等实根；\(\Delta \lt 0\)：无实根。

竞赛技巧：将问题转化为"某二次方程有实根"，从而建立 \(\Delta \geq 0\) 的不等式。这是求最值、证不等式的隐蔽手法。

1.4 试试韦达定理

韦达定理（Vieta's Formulas）

若 \(x_1, x_2\) 是 \(ax^2 + bx + c = 0\) 的两根，则：

\[x_1 + x_2 = -\frac{b}{a}, \qquad x_1 x_2 = \frac{c}{a}\]

韦达定理的价值：不需要求出根，就能用系数直接表达根的和与积。常用于构造方程、对称式求值、根的分布问题。

1.5 主元素方法

在多变量问题中，选定一个变量作为"主角"，将其他变量视为参数或常数，把问题化归为该变量的方程或不等式。这是一种化多为少的策略。

1.6 恰当放缩

常用不等式

AM-GM 不等式（均值不等式）：对正实数 \(a_1, a_2, \ldots, a_n\)，

\[\frac{a_1 + a_2 + \cdots + a_n}{n} \geq \sqrt[n]{a_1 a_2 \cdots a_n}\]

等号成立当且仅当 \(a_1 = a_2 = \cdots = a_n\)。

放缩的关键在于"恰到好处"——放得太多失去精确性，放得太少无法推进。需要在练习中积累经验。

第 二 部 分
几 何 篇

2.1 面积法

面积法是几何中最强大的工具之一：通过计算同一个图形的面积（用两种不同方式），建立等量关系，从而推导出线段比例、角度关系等。

面积法的常用公式

\(S = \frac{1}{2}ab\sin C\)（两边夹角）；\(S = \frac{1}{2} \cdot \text{底} \cdot \text{高}\)；\(S = \sqrt{s(s-a)(s-b)(s-c)}\)（海伦公式），其中 \(s = \frac{a+b+c}{2}\)。

2.2 平移、旋转与翻折

几何变换能将分散的条件"搬运"到一起：平移使平行关系显现，旋转将分散的角和线段集中，翻折构造对称点。旋转变换在等边三角形和正方形问题中尤为有效。

旋转变换的核心思想：若图形中有等边三角形或正方形，尝试绕其中心旋转 \(60°\) 或 \(90°\)，将分散的线段"拼接"成新的三角形。

2.3 利用相似

相似三角形的判定

AA（两角相等）、SAS（两边成比例且夹角相等）、SSS（三边成比例）。

若 \(\triangle ABC \sim \triangle DEF\)，则对应边之比相等，面积比等于相似比的平方。

2.4 几何不等式

几何不等式研究图形的度量关系。核心工具包括：三角形两边之和大于第三边、大边对大角、点到直线距离最短（垂线段）等。

2.5 四点共圆

四点共圆的判定

四点 \(A, B, C, D\) 共圆，当且仅当以下任一条件成立：

① 对角互补：\(\angle A + \angle C = 180°\)；② 同弧上的圆周角相等：\(\angle ADB = \angle ACB\)；③ 交弦定理：\(PA \cdot PB = PC \cdot PD\)（\(P\) 为两弦交点）。

2.6 代数方法

将几何问题坐标化或参数化，转化为代数方程求解。常见手段：建系法（解析几何）、三角法（用 \(\sin, \cos\) 表示线段和角）、向量法。

第 三 部 分
数 论 篇

3.1 奇数与偶数

奇偶分析是数论中最基本的"不变量"方法。通过判断某个量在操作前后的奇偶性是否改变，可以证明某些状态不可达。本质是模 2 同余。

3.2 素因数分析

利用算术基本定理（唯一分解定理），将整数分解为素因子的乘积，从而分析整除性、约数个数、最大公因数等问题。

\(n!\) 中素数 \(p\) 的幂次（Legendre 公式）
\[ v_p(n!) = \sum_{k=1}^{\infty} \left\lfloor \frac{n}{p^k} \right\rfloor = \left\lfloor \frac{n}{p} \right\rfloor + \left\lfloor \frac{n}{p^2} \right\rfloor + \left\lfloor \frac{n}{p^3} \right\rfloor + \cdots \]

3.3 选择合适的模

同余是数论的核心工具。关键是选择恰当的模 \(m\)，使得取模后问题的结构简化。常用模：\(m = 2\)（奇偶分析）、\(m = 3, 4\)（平方剩余分析）、\(m = p\)（费马小定理）。

3.4 作出恰当的估计

在数论中，许多问题可以通过不等式夹逼来缩小搜索范围。例如利用 \(\sqrt{n} \lt \lfloor\sqrt{n}\rfloor + 1\) 来限定完全平方数的范围，或利用 \(p \leq \sqrt{n}\) 来限定素因子。

3.5 最小数原理

最小数原理（Well-ordering Principle）

任何非空的正整数集合中，一定存在最小元素。

这一原理看似平凡，却是反证法和无穷递降法的理论基础：假设存在某个满足条件的正整数，取其中最小的一个，证明还存在更小的——矛盾。

3.6 存在性问题

数论中的存在性问题通常用构造法（给出一个具体例子）或反证法+抽屉原理来证明。关键是巧妙选取模或构造抽屉。

第 四 部 分
组 合 篇

4.1 抽屉原则

将 \(n+1\) 个物品放入 \(n\) 个抽屉，至少有一个抽屉含 \(\geq 2\) 个物品。加强形式：\(N\) 个物品放入 \(n\) 个抽屉，至少有一个含 \(\geq \lceil N/n \rceil\) 个。关键：如何构造抽屉。

4.2 染色或赋值

给对象赋予颜色或数值标签，构造不变量或对称结构。棋盘黑白染色是最经典的例子：利用黑白格数的奇偶性证明某些铺排不可行。

4.3 算两次

算两次（Double Counting）

对同一个量用两种不同方式计数，得到等式或不等式。

例如：统计"满足某关系的有序对 \((a, b)\) 的个数"，先按 \(a\) 计、再按 \(b\) 计，建立等式。

4.4 从局部到整体

先分析单个元素的局部性质，再利用整体约束（总和固定、总数有限等）推导全局结论。例如：已知每个点的度数，推断图的总边数。

4.5 将命题一般化

将特殊问题推广到一般情形，有时反而更容易证明。例如：\(n=3\) 时的结论不好证，但 \(n\) 为任意正整数时反而可以用归纳法。

4.6 先猜后证

先用小例子猜测答案（极值、构造方案等），再严格证明猜测正确。这是组合问题中最实用的策略：

先猜后证·步骤
步骤内容
① 试验对 \(n = 1, 2, 3, \ldots\) 分别求解，记录结果
② 猜测观察规律，提出猜想公式或构造方案
③ 上界证明任何方案都不超过猜测值
④ 构造给出一个恰好达到猜测值的方案
